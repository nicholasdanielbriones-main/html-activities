HTML DOM

The DOM (Document Object Model) shows this page as a tree of elements. I gave several elements an id (main-heading, hills-figure, dom-list) so I could find them in DevTools.

  • The html element is the root of the tree.
  • The head and body are its children.
  • Every tag inside body becomes a branch or leaf of the tree.
